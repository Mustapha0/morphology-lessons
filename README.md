# Understanding Morphology lessons

```
index.html          landing page (list of chapters)
ch3/index.html      chapter 3 content
ch4/index.html      chapter 4 content
chapter-template/   copy this to start a new chapter
assets/lesson.css   shared design
assets/lesson.js    shared engine (tiles, player, quizzes, example lab)
```

## Add a chapter
1. Copy `chapter-template/` to `ch5/` (or any name).
2. Edit `ch5/index.html`: write the sections, change the label at the bottom.
3. Add one line to the `CHAPTERS` list in `index.html`.

Fix or improve the look or the player once in `assets/` and every chapter updates.
